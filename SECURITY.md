# Security Policy

## Supported versions

Until the first release, security fixes target `main`. After releases begin, only the latest released version is supported unless a release note states otherwise.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue or pull request.

Use GitHub's private vulnerability reporting for this repository when available. If private vulnerability reporting is unavailable, create a public issue containing no sensitive details and ask the maintainer to establish a private contact channel before sharing the report.

Include enough information to reproduce and assess the issue, but do not include real Pocket ID API keys, generated OIDC client secrets, private infrastructure details, personal data or other credentials.
